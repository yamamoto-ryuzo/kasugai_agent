2-1 パネル構成

パネルは横3ペイン構成です。境界のグリップをドラッグすると幅を変えられ、
localStorage に永続化されます。

左ペイン

  • カレントリポジトリ選択 — title 直下の owner/repo 2セレクト。 常に1リポジトリを指し（「すべて」選択肢は無し）、選択がパネル全体の スコープ（新規 chat の cwd・課題化の repo・各一覧の絞込）になります。 localStorage に永続化
  • 管理セクション — loop state（version/port/repos/chats/candidates 数）と candidates 一覧を表示
  • 縦並びナビ — 各ビューへの入口（後述）

ナビボタン

ボタン表示先内容
AIチャット右ペインchat sessions 一覧に戻す
処理状況中央ペイン状態別カンバン列（「2-3 処理状況」）
エディター右ペインカレント repo のフォルダツリー（file 選択で中央に本文表示）
AGENTS右ペイン+中央agent 定義・ルール文書と参照ファイル一覧

マニュアル中央ペイン本サイト（docs/）を iframe で表示
設定中央ペイン接続AI / リポジトリ / システム（「2-5 設定」）
─（区切り線）
コミットカレント repo全変更をローカルコミット（POST /api/git/commit。git add -A + git commit、変更なしは noop）
プッシュカレント repoコミットをリモートへプッシュ（POST /api/git/push。人ゲートの承認）

git 系ボタンは区切り線を挟んでナビ末尾（設定の下）に並びます。
実行出力はコンソールタブへ集約されます（SSE push で即時表示）。

右ペイン

  • chat sessions — カレント repo の chat 一覧。行は状態ドット + ラベルの最小表示で、状態の確認は処理状況ボードで行う。 並列モードは親子でグループ表示。省略ラベルはホバーで全文ポップアップ （状態・並列/agent の補足も併記）
  • エディター — カレント repo のフォルダツリー。dir は lazy 展開 （GET /api/fs/tree）、file 選択で中央ペインに本文表示 （登録 repo 配下・非秘匿のみ）
  • doc browser — AGENTS/SKILL 選択時に doc + 参照ファイルを一覧

ヘッダ（中央ペイン）

チャット表示時は「最新・課題化・改名・中断・クリア・変更復元・リセット」
ボタン、doc/マニュアル表示時は「← チャット」で戻ります。右端の言語 select
で表示言語を切替（panel/i18n/ 辞書・localStorage 永続化）。
