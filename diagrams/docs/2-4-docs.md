title: 2-4 doc browser
---

右ペインの doc browser は、registry が収集した文書とその参照ファイルを
一覧・閲覧するビューです。

## AGENTS / SKILL

- **AGENTS** — agent 定義・ルール文書。doc 一覧ではなく、収集した全 doc の
  参照ファイルをマージして1つの一覧にする（AGENTS.md は1枚前提）
- **SKILL** — `SKILL.md` 一覧（global scope は一覧から除外。
  収集・参照解決の対象ではある）
- **参照ファイル** — doc 本文中のパス参照を抽出。実在・非秘匿なら
  クリックで開き、秘匿系は 🔒・未作成は無効表示

## doc 本文の表示（中央ペイン）

本文は Viewer 単一オブジェクトに描画を集約しています。

- **原文 / プレビュー切替** — kind 判定（md / html / mmd / その他）
- **md** — Markdown + mermaid 描画
- **html** — sandboxed iframe で描画
- **mmd** — mermaid 図として描画。縦⇄横ボタンで図の向きを表示のみ切替
- **拡縮** — mermaid 図は ＋−ボタン / ホイールで拡縮（カーソル位置維持）、
  ドラッグで視野移動

## マニュアル

「マニュアル」ナビは本サイト（`docs/`）を中央ペインの iframe で開きます。
右ペインの構成は変えないため、表示中のツリー/doc 一覧はそのまま
参照できます。
