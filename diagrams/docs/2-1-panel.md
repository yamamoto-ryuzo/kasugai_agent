---
title: 2-1 パネル構成
---

パネルは左・中央・右の3ペイン構成です。右ペインは常時表示で、
エディター/AGENTS/SKILL 選択時は doc browser / フォルダツリー、
それ以外（右ペインに出すものがない時）は管理セクションを表示します。
境界のグリップをドラッグすると幅を変えられ、
localStorage に永続化されます。

## 左ペイン

- **カレントリポジトリ選択** — title 直下の owner/repo 2セレクト。
  常に1リポジトリを指し（「すべて」選択肢は無し）、選択がパネル全体の
  スコープ（新規 chat の cwd・各一覧の絞込）になります。
  選択し直すと各一覧・中央ペインを再取得し、表示中の chat / doc 表示が
  スコープ外なら解除します（実行中の chat はバックグラウンドで継続します）。
  localStorage に永続化
- **縦並びナビ** — 各ビューへの入口（後述）

## ナビボタン

| ボタン | 表示先 | 内容 |
|---|---|---|
| 処理状況 | 中央ペイン | 状態別カンバン列（「2-3 処理状況」）。起動時の初期表示 |
| AIチャット | 中央ペイン | doc/ツリー表示を閉じてチャットに戻る |
| エディター | 右ペイン | カレント repo のフォルダツリー（file 選択で中央に本文表示） |
| AGENTS | 右ペイン+中央 | agent 定義・ルール文書と参照ファイル一覧 |
| SKILL | 右ペイン+中央 | SKILL.md 一覧（global scope は除外） |
| マニュアル | 中央ペイン | 本サイト（`docs/`）を iframe で表示 |
| 設定 | 中央ペイン | 接続AI / リポジトリ / システム（「2-5 設定」） |
| ─（区切り線） | | |
| コミット | カレント repo | 全変更をローカルコミット（`POST /api/git/commit`。`git add -A` + `git commit`、変更なしは noop） |
| プッシュ | カレント repo | コミットをリモートへプッシュ（`POST /api/git/push`。人ゲートの承認） |

git 系ボタンは区切り線を挟んでナビ末尾（設定の下）に並びます。
実行出力はコンソールタブへ集約されます（SSE push で即時表示）。

## 右ペイン

常時表示です。エディター/AGENTS/SKILL 選択時は doc browser /
フォルダツリーに切り替わり、それ以外（右ペインに出すものがない時）は
管理セクションを表示します。

- **管理セクション** — loop state（version/port/repos/chats/candidates 数）と
  candidates / issues / proposals 一覧を表示（既定表示）。
  candidates は人の判断待ちのみを表示する inbox で
  （未起票・gated・queued・failed。起票は自動が既定で、
  実行中・終端の課題行は出しません）、各行の「対応」「却下」
  ボタンで一括判断します。「対応」は起票・承認・再実行を兼ねた
  即時 dispatch（未起票は rate-limit を人判断で bypass）、
  「却下」は rejected です（未起票は起票して即 rejected）。
  proposals のカードはクリックで中央ペインに詳細（vet 検査結果・
  changes 本文・採否ボタン）を表示します
- **エディター** — カレント repo のフォルダツリー。dir は lazy 展開
  （`GET /api/fs/tree`）、file 選択で中央ペインに本文表示
  （登録 repo 配下・非秘匿のみ）
- **doc browser** — AGENTS/SKILL 選択時に doc + 参照ファイルを一覧

chat の切替は処理状況ボードのカードで行い、新規チャットは
チャットヘッダまたはボード上部の「＋ 新規チャット」で開きます。
ヘッダの「◀ 戻る / 進む ▶」ボタンでも前後の chat へ移れます
（並びは処理状況ボードと同じ。他 repo の chat はカレント repo の
切替を兼ねます）。

## ヘッダ（中央ペイン）

チャット表示時はタイトル前に処理状態ピル（ボードの列区分と同じ色で
実行中・検証中・要対応など）を表示し、
「＋ 新規チャット・最新・◀ 戻る・進む ▶・改名・中断・クリア・
変更復元・リセット」
ボタンを並べます。doc/マニュアル表示時は「← チャット」で戻ります。
右端の言語 select で表示言語を切替（`panel/i18n/` 辞書・localStorage 永続化）。
